# DEGEN PENSION 品牌 Playbook

## 1. 品牌核心

DEGEN PENSION 把一种简单纪律变成可见动作：

> **99% APE. 1% ADULT.**

99% 保留 Degen 的决断感，1% 让每笔通过 Gateway 的买入同时产生一笔独立披露的 Stock Token 配置。这里的 “PENSION” 与 “ADULT” 是品牌语言，不代表储蓄账户、养老金、收益或本金保障。

### 支持口号

- **梭哈归梭哈，养老归养老。**
- **99哥负责上头，1仔负责活到退休。**
- **FULL DEGEN. ONE PERCENT ACCOUNTABLE.**
- **SEND 99. ACCOUNT FOR 1.**
- **CHAOS, WITH A LEDGER.**

支持口号不能脱离 99/1 资金说明单独用于投资招揽。

## 2. 品牌角色

### 99哥

狂躁浣熊交易员，是 99% 项目币腿的人格化表达。

- 外形：浣熊、旧西装、酸绿领带、夸张但可爱的亢奋表情。
- 动作：前冲、拍下买入键、指向项目币输出。
- 语气：短、快、全大写感、行动导向。
- 职责：制造注意力，解释“99% 去哪里”。
- 禁区：不喊保证上涨、稳赚、退休自由、内幕、百倍或无风险。

99哥可以说：“99% TO PROJECT TOKEN.”

99哥不能说：“THIS WILL 100X.”

### 1仔

冷脸迷你会计，是 1% Stock Token 腿和事实核验的人格化表达。

- 外形：迷你灰色会计、旧账本、酸绿帽带、永久冷脸。
- 动作：核对费用、CA、资格与成交收据。
- 语气：冷静、精确、少字，不卖弄金融术语。
- 职责：解释“1% 来自哪里”、费用和失败条件。
- 禁区：不扮演投资顾问，不推荐个股，不承诺分红、收益或可赎回性。

1仔可以说：“THE 1% COMES FROM YOUR PRINCIPAL.”

1仔不能说：“FREE STOCK.”

### 二者关系

99哥负责冲，1仔负责把账写清楚。两者不是“风险与安全”的绝对对立；Stock Token 仍有市场、发行人、流动性和监管风险。

## 3. 视觉系统

### 色彩

- 深黑：`#080907`，主背景。
- 酸性绿：`#C8FF3D`，99%、主要动作和可用状态。
- 警报橙：`#F06745`，风险提示和异常状态。
- 旧账本暖白：`#F0E7CF`，主标题、数值和高优先级正文。

色彩使用平涂，不使用渐变。绿色不能单独表示“安全”或“保证”，橙色也不能让 1% 看起来像错误或惩罚。

### 字体与版式

- 标题使用超粗、紧凑、高对比的无衬线字体。
- 数据使用清晰的等宽或窄体字体。
- 采用交易终端式网格、硬边框、分隔线和大字号数值。
- 交易面板保持为一个连续表面，避免卡片套卡片。
- 优先显示：本金 → 99/1 分流 → 两腿输出 → 费用 → CTA。

### 插画

- 半写实漫画、粗墨线、网点阴影、丝网印刷纹理和撕纸贴纸边缘。
- 角色可以突破网格边缘，但不得遮挡 CA、费用、资产名称或最小输出。
- 禁止 3D 金币、漂浮硬币、Emoji、玻璃拟态、设备框、浏览器框和水印。

## 4. 产品文案规则

### 必须使用

- `PROJECT TOKEN`
- `STOCK TOKEN`
- `99% APE. 1% ADULT.`
- `CONNECT WALLET`
- “1% Stock Token 使用你的本金购买。”
- “Direct DEX/Pons buys do not include the 1% Stock Token.”

### 禁止或必须改写

| 禁止表达 | 正确表达 |
| --- | --- |
| 免费送股票 | 本金的 1% 用于购买 Stock Token |
| 项目币自带 1% 股票 | 通过官方 Gateway 成交时执行独立的 1% Stock Token 腿 |
| 买哪里都有 1% | Direct DEX/Pons 买入不包含 1% |
| 持有真实股票 | 持有明确披露的 Stock Token；其法律性质以发行人文件为准 |
| 保本、稳赚、养老保障 | 不作收益、本金或退休保障承诺 |
| Robinhood 官方合作 | 仅在获得可公开验证的正式授权时使用 |

## 6. 延迟与暂停模板

### 尚未 MarketReady

```text
$[TICKER] CA has been detected, but the 99/1 Gateway is NOT MARKET READY.

Do not use links or Gateway addresses posted in replies or DMs.
We will publish the verified CA and official Gateway together after all checks pass.
```

### 发布后暂停

```text
99/1 Gateway buys for $[TICKER] are temporarily paused.

New Gateway orders will fail closed while we verify [ROUTE / ORACLE / MARKET STATUS].
Direct DEX/Pons trades are separate and do not include the 1% Stock Token.

Do not use alternate contracts or links shared in replies or DMs.
```

暂停文案不得暗示问题已解决；恢复时必须重新产生有效 MarketReady Artifact。

## 7. 反诈骗传播规范

- 正式推文同时发布项目 CA 与官方 Gateway 链接，避免两条消息被拆开伪造。
- 使用完整域名，不使用短链，不通过 URL 参数覆盖 CA、Gateway 或 Stock Token。
- 置顶正式 MarketReady 推文，并从官网状态页双向链接。
- 官方人员绝不通过私信发送替代 CA、临时 Gateway、助记词请求或签名恢复请求。
- 不要求用户分享助记词、私钥、屏幕控制权或远程访问权限。
- 提醒用户按链 ID 和完整校验和地址核对，不按 Ticker、头像或搜索结果判断。
- 官方账号不在评论区发布“更新后的 CA”；地址变化必须形成新的正式发布和版本记录。
- 发现仿冒时，保留证据、举报账号，并在原始置顶推文和状态页同步警告。
- 社区管理员只能引用官方状态页，不得口头确认未经 Artifact 验证的地址。
- 所有传播必须重复说明：Direct DEX/Pons 买入不包含 1%，Stock Token 资金来自用户本金而非赠送。

## 8. 品牌合规底线

有趣可以激进，事实不能含糊。任何视觉、角色台词或社交文案只要可能让用户误以为 Stock Token 免费、任何买入渠道都有 1%、项目得到 Robinhood 背书，或产品承诺收益，就必须在发布前删除或改写。
